# MaquisTech — installateurs Windows

Ce dépôt ne contient **aucun code source**. Il sert uniquement à distribuer les
installateurs de l'application de caisse Windows **MaquisTech** et à alimenter
sa mise à jour automatique.

## Télécharger

La dernière version se trouve dans [Releases](../../releases/latest).
Téléchargez le fichier `MaquisTech-Setup-<version>.exe` et exécutez-le.

> L'installateur n'est pas signé numériquement : Windows SmartScreen affiche un
> avertissement au premier lancement. Cliquez sur **Informations complémentaires**
> puis **Exécuter quand même**.

## Mise à jour automatique

Une fois installée, l'application vérifie seule les nouvelles versions, les
télécharge en arrière-plan et les installe à sa fermeture. Aucune
réinstallation manuelle n'est nécessaire.

## À propos

MaquisTech est une solution de gestion pour restaurants et maquis :
menu par QR code, commandes en temps réel, livraison, fidélité.
